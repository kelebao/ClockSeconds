# Δευτερόλεπτα στη γραμμή κατάστασης (Show Seconds in Time)

Δείχνει τα **δευτερόλεπτα** στο ρολόι της γραμμής κατάστασης, εναλλαγή με άγγιγμα. Μπορείτε να δώσετε **χρώμα σε κάθε ψηφίο** ή να εφαρμόσετε **διαβάθμιση** σε όλο το κείμενο.<br>**Παρατεταμένο πάτημα** ανοίγει ημιδιαφανές παράθυρο με την **ώρα δικτύου** (μετακίνηση, μέγεθος, διαβάθμιση)· οι **δικές σας εργασίες** ενεργοποιούν τα δευτερόλεπτα στην ώρα που θέλετε.<br>Η κύρια διαδρομή χρησιμοποιεί μόνο δημόσια API του AOSP (οι κλειστές κλάσεις OPPO / OnePlus / realme είναι προαιρετικές και παραλείπονται αν λείπουν). Δοκιμασμένο σε ColorOS 15 / 16.

## Δυνατότητες

| Δυνατότητα | Λεπτομέρειες |
|------|------|
| Δευτερόλεπτα στη γραμμή | `HH:mm:ss` / `h:mm:ss a`, σέβεται τη μορφή 12/24 ωρών και τη ζώνη ώρας. Στο τέλος προστίθεται **κενό μηδενικού πλάτους** ώστε τα θέματα να μη σβήνουν τα χρώματα· αν χαθούν, το κείμενο ξαναζωγραφίζεται αυτόματα (παύση 5 λεπτών). |
| Εναλλαγή με άγγιγμα | **Άγγιγμα** της ώρας ενεργοποιεί/απενεργοποιεί τα δευτερόλεπτα (μπορείτε να διαλέξετε **διπλό άγγιγμα**)· το **παρατεταμένο πάτημα** ανήκει στο παράθυρο προεπισκόπησης. Μέσα σε εργασία εμφανίζεται μήνυμα ότι την ελέγχει η εργασία. |
| Χρώμα ανά ψηφίο / διαβάθμιση | Έξι ψηφία **το καθένα με δικό του χρώμα** (10 έτοιμα + ρυθμιστικά HSV + χρώμα συστήματος) και οι δύο τελείες οπτικά κεντραρισμένες. Ή **διαβάθμιση** από το αρχικό στο τελικό χρώμα (6 σετ, επεξεργάσιμα άκρα, σκουραίνει σε ανοιχτό φόντο). Η κάρτα προεπισκόπησης **ζωγραφίζεται μόνη της** κι έτσι ταιριάζει με τη γραμμή κατάστασης. |
| Παράθυρο με παρατεταμένο πάτημα | Ημιδιαφανές παράθυρο με την **ώρα δικτύου**· σύρετε για μετακίνηση, γωνία ◣ για μέγεθος, θέση και μέγεθος **απομνημονεύονται**· διαβάθμιση και ψηφία ίσου πλάτους. |
| Δικές σας εργασίες | Παράθυρα **κάθε ώρα** ή **κάθε μέρα**: ενεργοποίηση δευτερολέπτων N λεπτά πριν για M λεπτά και επαναφορά. Αλλαγή ώρας ή ζώνης επανυπολογίζεται αμέσως, με έλεγχο κάθε 60 δευτερόλεπτα. |
| Σύγκριση με ώρα δικτύου | Δείχνει την απόκλιση από την **ώρα δικτύου**· το κουμπί **Συγχρονισμός** ενεργοποιεί την αυτόματη ώρα του συστήματος. |
| Χωρίς adb | Η εγγραφή γίνεται μέσω `Settings.Secure`· χωρίς `WRITE_SECURE_SETTINGS` ένα broadcast αναθέτει την εγγραφή στο SystemUI — **καμία λειτουργία δεν χρειάζεται adb**. |
| Πλακίδιο γρήγορης ρύθμισης | Προσθέστε το πλακίδιο «Εμφάνιση δευτερολέπτων» για εναλλαγή χωρίς άνοιγμα της εφαρμογής. |
| Όνομα πόρου ρολογιού | Αν το ρολόι δεν αναγνωριστεί, πατήστε **Αυτόματη ανίχνευση** ή γράψτε το όνομα πόρου (π.χ. `clock`). |
| 21 γλώσσες διεπαφής | Ακολουθεί τη γλώσσα του συστήματος: 简体中文, English, 繁體中文, 日本語, 한국어, Türkçe, Русский, Tiếng Việt, ไทย, Deutsch, Español, Français, Українська, Polski, Português (Brasil), فارسی, العربية, Bahasa Indonesia, Italiano, Ελληνικά, ქართული· τα υπόλοιπα αγγλικά. |
| Αποθήκευση / εμβέλεια | Η κατάσταση βρίσκεται στο `Settings.Secure`, κοινή μεταξύ διεργασιών και παραμένει μετά από επανεκκίνηση. **Δοκιμασμένο σε ColorOS 15 / 16 (Android 15 / 16)**· ο πυρήνας χρησιμοποιεί μόνο δημόσια API, άρα άλλοι κατασκευαστές θα έπρεπε να δουλεύουν, αλλά δοκιμάστηκαν μόνο OPPO / OnePlus. Ελάχιστο Android 10. |

## Εγκατάσταση

1. Κατεβάστε το APK από τη σελίδα [**Releases**](https://github.com/kelebao/ClockSeconds/releases/latest)
2. Ενεργοποιήστε τη μονάδα στο **LSPosed** και επιλέξτε πεδίο **Διεπαφή συστήματος** (`com.android.systemui`)
3. Επανεκκινήστε τη διεργασία SystemUI ή τη συσκευή
4. Η οθόνη ρυθμίσεων ανοίγει από τον **διαχειριστή LSPosed** (δεν δημιουργείται εικονίδιο)

> Απαιτείται root (LSPosed). **Συνήθως δεν χρειάζονται δικαιώματα adb**: η εγγραφή γίνεται μέσω `Settings.Secure` και, χωρίς `WRITE_SECURE_SETTINGS`, μέσω broadcast που εκτελεί το SystemUI. Για να γράφει **απευθείας** η οθόνη ρυθμίσεων:
> ```bash
> adb shell pm grant io.github.kelebao.colorosclockseconds android.permission.WRITE_SECURE_SETTINGS
> ```
> Χωρίς παροχή όλα λειτουργούν: αγγίγματα, εργασίες και παράθυρο τρέχουν μέσα στο SystemUI.

## Χρήση

- **Αγγίξτε την ώρα**: δευτερόλεπτα on/off (προεπιλογή)· στις ρυθμίσεις μπορείτε **διπλό άγγιγμα**.
- **Παρατεταμένο πάτημα**: ημιδιαφανές παράθυρο με την **ώρα δικτύου**, σύρετε για μετακίνηση· αγγίζοντας την ώρα εμφανίζονται **κλείσιμο** (πάνω δεξιά) και **μέγεθος** (κάτω αριστερά).
- Η κάρτα **Χρώματα ψηφίων** έχει δύο σελίδες και η ίδια η καρτέλα είναι ο διακόπτης.
- Η κάρτα **Δικές σας εργασίες** προγραμματίζει παράθυρα όπως «δευτερόλεπτα 2 λεπτά πριν από κάθε ώρα».
- Η εναλλαγή χρησιμοποιεί καθολικό έλεγχο αγγίγματος και **δεν συγκρούεται με το τράβηγμα** του πίνακα.

## Πώς λειτουργεί

Η μονάδα αγκιστρώνει μόνο το **SystemUI** και χρησιμοποιεί το σταθερό legacy API του Xposed.
**Ο πυρήνας βασίζεται μόνο σε δημόσια API του AOSP· οι κλάσεις κατασκευαστή είναι προαιρετικές και παραλείπονται όταν λείπουν**, ώστε να μη σπάει το σύστημα και να μην ενεργοποιεί την ασφαλή λειτουργία του LSPosed:

- **Δευτερόλεπτα**: το `TextView.setText` (after) αποθηκεύει το κείμενο συστήματος και το `TextView.onDraw` (before) γράφει `αρχικό:ss`, με ανανέωση κάθε δευτερόλεπτο μέσω `Handler`.
- **Χρώμα ανά ψηφίο**: ένα `ForegroundColorSpan` ανά χαρακτήρα (ξένα span αφαιρούνται)· οι τελείες ανεβαίνουν 0.11em γιατί οι διατάξεις με πολλά τμήματα τοποθετούν το γλύφο χαμηλότερα.
- **Διαβάθμιση**: το `CharacterStyle` καλεί το `setShader` στο `updateDrawState`· η προεπισκόπηση **ζωγραφίζεται μόνη της** (`GradientTimeView`) γιατί το ColorOS 15 κβαντίζει το shader ανά τμήμα κειμένου.
- **Εναλλαγή**: ο πίνακας καταπίνει τα αγγίγματα στη γραμμή, οπότε η μονάδα αγκιστρώνει καθολικά το `View.dispatchTouchEvent` και αλλάζει μόνο όταν το άγγιγμα πέφτει μέσα στο ρολόι χωρίς σύρσιμο· το συμβάν **δεν καταναλώνεται**.
- **Εργασίες**: έλεγχος «είναι η τοπική ώρα στο παράθυρο», ακριβείς χρονιστές στα όρια και έλεγχος κάθε 60 δευτερόλεπτα.

## Κατανάλωση

- **Δευτερόλεπτα on**: χρονιστής κάθε δευτερόλεπτο (αναπόφευκτο κόστος). Μέτρηση SystemUI ανά πυρήνα: 7.0% off, 7.25% on (60 s).
- **Δευτερόλεπτα off**: ο χρονιστής **σταματά αμέσως** (`stopTicker`), χωρίς αφυπνίσεις ανά δευτερόλεπτο.
- Η **προστασία χρώματος** επιβραδύνει 2s → 4s → … → 30s και σταματά μετά από 5 λεπτά χωρίς απώλειες.
- Η κατάσταση **αποθηκεύεται προσωρινά στη διεργασία**· οι εργασίες χρησιμοποιούν `Handler.postDelayed`: **χωρίς WakeLock και AlarmManager**, δεν ξυπνούν τον βαθύ ύπνο.

## Μεταγλώττιση

Χρειάζονται **JDK 17+** (17 ή 21) και **Android SDK Platform 35** (το AGP κατεβάζει Build-Tools 35).

```bash
export JAVA_HOME=/path/to/jdk-17-or-21
./gradlew assembleDebug
```

## Αντιμετώπιση προβλημάτων

<details>
<summary>Δείτε τα βήματα</summary>

Δείτε το logcat:

- Οι **εκδόσεις Release** κρύβουν όλα τα διαγνωστικά logs πίσω από το `BuildConfig.DEBUG`.
- Για αποσφαλμάτωση εγκαταστήστε **build debug** (`assembleDebug`, ίδιο κλειδί) και φιλτράρετε:

  ```bash
  adb logcat -s ColorOSClockSeconds
  ```

- Δεν εμφανίζονται δευτερόλεπτα: ελέγξτε το πεδίο «Διεπαφή συστήματος» στο LSPosed και επανεκκινήστε· μετά διαβάστε ή γράψτε τον διακόπτη:

  ```bash
  adb shell settings get secure coloros_clock_seconds_enabled   # 1=on 0=off
  adb shell settings put  secure coloros_clock_seconds_enabled 1
  ```

- Χρώματα ή δευτερόλεπτα επιστρέφουν μόνα τους: το σύστημα ή το θέμα ξαναχτίζει το κείμενο και η μονάδα ξαναζωγραφίζει· αν δεν επανέλθει, ψάξτε στο log debug για `color-guard stopped` / `span-theft`.

</details>
