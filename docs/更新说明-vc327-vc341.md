## 一、安装与升级

1. 覆盖安装（保留数据）：

```bash
adb -s <设备序列号> install -r -t D:/MyApp/_dist/ClockSeconds-vc340-modern-api102-debug.apk
```

2. 安装后重启 SystemUI，让 LSPosed 重新注入新模块代码：

```bash
adb -s <设备序列号> shell su -c "killall com.android.systemui"
```

3. 若状态栏没有变化，确认 LSPosed 中本模块作用域已勾选 **com.android.systemui**，再重启一次 SystemUI。

## 二、最值得看的七件事

1. **高级设置变成独立工作台**：顶部固定导航 +「单色 / 渐变」两页，页内共享一枚实时预览钟，改哪一位、看哪一位。
2. **顶部导航重做**：一枚左右留边、铺满整排的一体胶囊，左侧返回 `‹`，右侧单色 / 渐变各占一半；选中态是紫色文字 + 底部短指示线，不再是紫色实心块。
3. **卡片也能「呼吸」**：系统模式自适应与预览时间合并为一张卡，标题居中、时间作视觉主角，底部紫红光晕托底；卡片底边裁剪到时间附近，不再拖一大片空白。
4. **深浅色真正分开**：深色 / 浅色各一套 12 个自定义预设，系统切深浅色时自动换用对应一套；「系统模式自适应」开关旁的问号会解释这套逻辑。
5. **渐变方向扩充到 10 种**：竖直、水平、对角线、右→左、下→上、右下↖、右上↙、左下↗、径向、扫掠；方向行右侧有动态 `⇆` 箭头提示可横滑。
6. **预览取景框贴合数字**：单色页点某一位数字时出现的相机取景框，从「整行字高」缩到「数字实际墨迹高度」，四角完整、不再被卡片底边裁掉。
7. **16 进制色号与端点调色盘（vc341）**：调色盘三条滑杆下新增「色号」输入框，支持 `#RGB / RGB / #RRGGBB / RRGGBB`；渐变端点选中后再点一次，直接弹出 HSV 调色盘；首页卡片拖动不再整卡倾斜。

## 三、高级设置页：从参数表到工作台

### 1. 页面结构

- **入口分页**：首页「单色 · 高级」进入高级设置的单色页；「渐变 · 高级」进入渐变页。进入哪一页由首页当前停留的页签决定。
- **固定顶部导航**：返回、单色、渐变所在的一体胶囊固定在状态栏下方，页面内容上下滚动时导航不移动。
- **单色页**：逐位数字色编辑 + 调色盘 + 我的预设；当前编辑位有紫色取景框标记。
- **渐变页**：起点色 / 终点色两个圆点编辑 + 方向胶囊 + 我的预设；两枚圆点居中、左右等距，不再显示 ①② 文字标签，编辑行仍会说明正在编辑「起点色 / 终点色」。
- **共享预览钟**：首页与高级设置复用同一套预览组件，预览看到的时间配色与状态栏使用同一套渲染规则。

### 2. 系统模式自适应

- 「系统模式自适应」= **跟随系统深浅色模式**，不是逐帧分析壁纸。
- 开启后，六位数字和渐变两端各有一套「深色模式用」与「浅色模式用」颜色；系统切到深色用深色套，切到浅色用浅色套。
- 卡片内的「深色 / 浅色」页签决定**当前正在编辑哪一套颜色**；实际显示仍由系统深浅模式决定。
- 标题行右侧的 **?** 问号是功能说明入口，点开解释「为什么需要两套颜色、页签与系统模式的关系」。

### 3. 我的预设

- 深色、浅色两组各最多 **12 个**自定义预设，按保存时间倒序排列，新建的在最前。
- **保存当前**：把当前逐位颜色或渐变两端颜色 + 渐变方向一起存成预设。
- **应用预设**：单色预设只出现在单色页，渐变预设只出现在渐变页；应用渐变预设会同时恢复方向与两端颜色。
- **长按预设**：弹出重命名 / 删除菜单；删除有二次确认，操作结果会真实写盘（此前「toast 说成功但文件没变」的假成功已修）。
- **问号帮助**：预设标题行右侧的 **?** 会提示「长按预设颜色可删除或重命名」。
- **更多 / 全量管理页**：按页类型过滤、3 列网格展示全部预设，支持长按重命名、删除、查看「使用中」标记。

### 4. 视觉与交互细节

- 深色 / 浅色两套预览背景板随页签切换；换配色面板本身不再铺整块深色背景，只保留预览区域的主题色。
- 选中页签为紫底白字；未选中为低透明度底色，深浅色下都清晰。
- 数字颜色、预览钟、状态栏三者共用同一套「生效色解析」：副键有真色时优先，副键为「跟随系统」时回落常规键，避免预览与状态栏各显示一套颜色。

## 四、渐变：两色端点 + 11 种方向

### 1. 端点

- 界面简化为 **起点色 / 终点色** 两个圆圈；四色时代的中间键保留在配置层用于兼容旧数据，但界面不再暴露中间色标。
- 点圆圈选中后，下方色板与 HSV 三条滑杆编辑该端点；选中圆有涟漪反馈。
- 起点 / 终点颜色会同时用于预览钟、状态栏和悬浮时间，三者渲染规则一致。

### 2. 方向

当前方向行共 **11 个胶囊**：

| 类别 | 方向 |
|---|---|
| 基础 | 上→下、左→右 |
| 特效 | 象限光晕 Mesh、颗粒噪点 Grain、镀铬金属 Chrome、斜纹糖果 Stripes、波浪切割 Wave-Slice、低多边形 Low-Poly、水磨石 Terrazzo、二维码 QR Code、液态水银 Mercury |

- 方向行可横向滑动，标题行右侧的 `⇆` 会做往返平移动画提示可滑。
- 所有特效方向都跟随用户选择的起点色 / 终点色，不是固定配色。
- 旧方向值（2..9）保留兼容，老预设仍能正确回显并渲染。

### 3. 渐变预设与任务配色

- 渐变预设会记录「方向 + 起点色 + 终点色」，应用时三样一起恢复。
- 自定义任务「换配色」面板：
  - 只展示用户保存的预设，不再混入内置渐变胶囊；
  - 深色 / 浅色页签切换时，面板文字、选中态、预览背景板一起换主题；
  - 单色预设画成 **6 段等宽纯色条**（不再错误地画成双色渐变）；渐变预设画成真实渐变条；
  - 勾选徽标落在被点胶囊的右下角，多选不会错位；
  - 预览时间按当前方案的实际渐变方向绘制。

## 六、自定义任务相关

- 定时任务可执行「显示秒数 / 隐藏秒数」，并新增按系统深浅色切换的配色动作。
- 任务换配色支持多套方案轮换；轮换下标持久化，SystemUI 重启后从上次位置继续，不会总从第一套开始。
- 任务配色预览会按每套方案自己的渐变方向渲染，不再统一按某个默认方向画。
- 修改系统时间、时区、休眠唤醒后自动重算窗口，另有每 60 秒兜底重算。
