# ClockSeconds v1.2.0 更新说明

> 适用版本：正式版 versionCode 249 / `1.2.0`（测试线从 vc37 累积到 vc249）
> 状态：**已发布正式 Release**（GitHub tag `v1.2.0`，versionCode 249），以下即 1.2.0 的更新清单。
> 一行概括：从「只能给小时上色」升级为「6 位数字各自取色 + 两色渐变 + 自定义任务 + 悬浮时间同款渐变」。

---

## 一、最值得看的三件事

1. **时分秒 6 位数字可以各自上色了**，还带一个能点开、能发光的预览卡。
2. **时间可以做成两色渐变**（起点色 → 终点色），有 6 套现成配色，也能自己调。
3. **可以设任务，到点自动显秒 / 到点自动关秒**（比如整点前 2 分钟自动打开秒数）。

---

## 二、新功能

### 1. 数字颜色：6 位独立取色

- **逐位上色**：时十位、时个位、分十位、分个位、秒十位、秒个位各自一个颜色，存在系统 Secure 里；状态栏按位给每个字符补 `ForegroundColorSpan`。
- **三种取色方式**：10 颗预设色点（点一下立即生效）、色相 / 饱和度 / 明度三条滑杆精细调、调色盘取色；另有「跟随系统」。
- **点预览时间展开取色**：轻点预览卡，数字放大、字距拉开，下面两张统计卡平滑收起；展开后**直接点某一位数字**即选中那一位。
- **选中位有下划线**：按该位字形宽度画一根同色短线，随选中位移动，比「放大」更稳、不撑破排版。
- **选中位发光呼吸**：2 秒一个来回，颜色跟该位当前颜色；亮色是霓虹感、深色是柔和光环。展开动画期间不亮，落定后才开始呼吸。
- **其余位变淡**：未选中位降到 30% 不透明度（保留色相，不改成暗色），一眼看出正在调哪一位。
- **等宽数字**：秒数跳动时整行不左右抖，下划线和光晕钉在字上不动。

### 2. 渐变（两色）

- **整串渐变**：起点色 → 终点色铺满整条时间文本；默认关闭，停在「渐变」页签即启用。
- **页签就是开关**：数字颜色卡分为「逐位颜色 | 渐变」两页，切到渐变页 = 开渐变，切回逐位页 = 关渐变。
- **6 套渐变预设胶囊**：一眼看出配色，点一下同时写入起点色与终点色。
- **端点色可自定义**：点「起点色 / 终点色」胶囊，下面的色板与三条滑杆改为编辑该端点；选中时色点外有**双涟漪呼吸**。
- **预览与状态栏完全同源**：同一套配色规则、同一个着色类，做到「预览看到的就是状态栏显示的」（含浅色背景自动压暗的规则）。
- **不自绘、零额外开销**：给文本挂一个自定义 `CharacterStyle`，完全搭在时钟本来就有的每秒重绘上，不加定时器、不加重绘循环。

### 3. 自定义任务（到点自动显秒 / 关秒）

- **触发方式**：每小时 / 每天，指定「时:分」。
- **提前开始**：可提前 N 分钟开始（例如整点提前 2 分钟）。
- **持续时长**：N 分钟。
- **动作**：到点**显秒**或到点**隐藏秒**（隐藏秒时保留颜色）。
- **时间校正**：改系统时间、改时区、休眠唤醒后会自动重算窗口，另有每 60 秒兜底重算，最坏情况延迟不超过 1 分钟。
- **任务期间点状态栏时间**：不再偷偷改总开关，改为弹提示「任务进行中：显秒已由「自定义任务」接管」。

### 4. 悬浮时间（长按状态栏时钟）

- **支持渐变**：与状态栏同款渐变，1 秒内自动跟随配置变更。
- **等宽数字**：修掉「渐变会流动」的错觉——原因其实是比例字形宽度随秒数变化导致色带被重新拉伸。

### 5. 设置页

- **粉尘点阵标题**：「时间显秒」由约 9 千个微小圆点组成，进页面时从左到右聚拢成字，点一下会炸开再聚回。
- 卡片按压倾斜、光晕呼吸等细节打磨。

## 三、修复清单（用户实际反馈过的）

| 问题 | 结论 |
|---|---|
| 预览时间里的渐变和状态栏有色差，个别颜色才有 | 状态栏会把亮度 > 0.55 的亮色压暗成深棕；阈值放宽到 0.85，并让两边共用同一套配色函数 |
| 个别分辨率下预览时间数字下段没了一半 | 展开时数字墨迹高超出预览小板可用高度；改为按实测墨迹高反推字号上限 + 运行时兜底 |
| 点状态栏时间没反应 | 正好落在自定义任务窗口内，任务接管了显秒；现改为弹 Toast 说明并**不再偷改**总开关 |
| 单色模式预览时间的冒号往下掉了 | 文本被切成多段绘制时冒号落基线；新增 `ColonLiftSpan` 抬 0.11em，逐位模式与数字中心对齐 |
| 关掉颜色总开关，预览时间还是彩色 | 预览的渐变分支没看总开关；补上判断，关闭即回默认文字色 |
| 端点色呼吸「散光」看不清 | 换成双涟漪：两圈同心环错相向外扩散并淡出 |
| 任务开关点一次没生效 / 保存后列表不刷新 / 到点秒数僵住 | 开关一次点击即写盘、保存后立刻刷新列表、秒数每秒重写不再靠幂等短路卡住 |
| 打开自定义任务界面状态栏消失 | 弹窗主题自带全屏标记；清掉并改为状态栏透明 |
| 设置页顶部多一条空白带 | 系统已把窗口下移时不再重复留白 |
| 展开态整行偏右 / 数字被挤成两行 / 光晕与字形错位 | 字距与墨迹测量系列事故，已按实测校正（首位不补字距、量字用零字距、量行用带字距） |

## 四、行为变化（升级须知）

- **「流动」功能已移除**（含流动开关与流动速度滑杆）：只保留静态渐变，状态栏 CPU 回到基线（SystemUI 单核约 7%，此前开流动约 40%）。
- **「省电自适应」已移除**：省电模式下不再暂停走秒，只有熄屏/非交互时降低刷新频率。
- **「启用渐变」开关已移除**：页签即开关。
- **「小时颜色」独立卡已移除**：并入「逐位颜色」。
- **单色预设精简为 10 颗**，「跟随系统」并入色板区。
- **「正在编辑：xx」提示行已移除**（与选中位光晕重复）。
- **四色渐变**：试做过，按需求撤回，目前只有两色。

---

## 五、已知限制

- **任务窗口要留足时长**：若设成「提前 2 分钟 + 持续 1 分钟」，窗口只有 1 分钟，深睡/重启等极端情况可能整段错过，建议持续 ≥ 5 分钟。
- **冒号颜色不可自定义**：ColorOS 的状态栏冒号由系统用白色绘制，不属于模块可控的文本段。
- **状态栏字体不可改**（已确认不做）：状态栏时钟是 ColorOS 自己的 TextView，模块只负责上色，不接管字体与排版。
- **渐变仍只有两色**（起点 / 终点）。

## 六、安装 / 升级

1. LSPosed 中启用模块，作用域勾选 **com.android.systemui**。
2. 安装本版 APK（与线上版本**同一签名**，可直接覆盖安装，不必卸载）。
3. **安装后需要重启 SystemUI 才会加载新的 hook 代码**：设置页内有「重启 SystemUI」按钮，或 `adb shell su -c 'killall com.android.systemui'`。
4. 开机后首次进设置页会重新读取配置；颜色、渐变、任务都写在 `Settings.Secure`，卸载重装不会丢。
