# ClockSeconds v1.2.0 正式版更新说明

| 项目 | 内容 |
|---|---|
| 版本 | **v1.2.0**（versionCode 249） |
| 包名 | `io.github.kelebao.colorosclockseconds` |
| 适用环境 | Android 10 及以上；已在 ColorOS 15 / 16（Android 15 / 16）真机验证，一加 / OPPO 直接可用；其它厂商走通用适配（核心链路只用 AOSP 公开 API），尚未逐一真机验证 |
| 运行方式 | LSPosed 模块，作用域 **com.android.systemui** |
| 签名 | 与 1.0.x 系列相同（SHA-256 前 8 位 `2850e82a`），可直接覆盖安装 |
| 升级自 | v1.0.9 及更早版本（1.1.0 未单独发版，其改动已并入本版） |

> **一句话**：这一版把「状态栏时间」从一个开关，做成了一个可自由配色、可定时、可预览的完整工具。

---

## 为什么值得升级

1. **时分秒 6 位数字可以各自上色**，还能点开预览卡逐位调，改哪一位、看哪一位。
2. **两色渐变**：起点色 → 终点色，6 套现成配色 + 自定义端点色，预览与状态栏完全一致。
3. **定时任务**：到点自动显示秒 / 到点自动隐藏秒，例如「整点前 2 分钟自动开秒」。

---

## 新增功能

### 数字颜色：6 位独立取色
- 时十位、时个位、分十位、分个位、秒十位、秒个位各一个颜色，支持 **10 颗预设色点 / 色相·饱和度·明度三条滑杆 / 调色盘 / 跟随系统**。
- **点预览时间展开取色**：数字放大、字距拉开，下面两张统计卡平滑收起；展开后直接点某一位数字即选中该位。
- 选中位显示**同色下划线**并做 **2 秒一循环的发光呼吸**；其余 5 位降到 30% 不透明度，正在调哪一位一目了然。
- 等宽数字排版：秒数跳动时整行不再左右抖动。

### 渐变（起点色 → 终点色）
- 数字颜色卡分为**「逐位颜色 ｜ 渐变」两页**，**停在哪页就是哪种模式**，页签即开关。
- 内置 **6 套渐变预设**，点一下同时套用两端颜色；端点色也可单独自定义。
- 端点色被选中时，色点外有**双涟漪呼吸**提示当前编辑目标。
- 预览与状态栏共用同一套配色规则与着色实现，做到「预览看到的，就是状态栏显示的」。

### 自定义任务（到点自动显秒 / 关秒）
- 触发方式支持**每小时 / 每天 + 指定时刻**，可设定**提前 N 分钟开始**、**持续 N 分钟**。
- 动作可选**显示秒数**或**隐藏秒数**（隐藏秒时保留颜色）。
- 修改系统时间、切换时区、休眠唤醒后自动重算窗口，并每 60 秒兜底重算一次。
- 任务生效期间点击状态栏时间，会明确提示「任务进行中：显秒已由自定义任务接管」，不会静默改变你的总开关。

### 悬浮时间（长按状态栏时钟）
- 支持与状态栏相同的渐变配色，配置变更 1 秒内自动跟随。
- 采用等宽数字，长时间观察不再出现色带「游走」的错觉。

### 稳定性与自诊（并入自 1.0.9 之后的所有改动）
- **ColorOS 17 原生「显示秒」强制常开**：系统自带的「5 分钟后自动收回」不再生效；私有类不存在时静默降级，不影响其它机型。
- **ColorOS 17 显秒掉色根治**：修复系统与第三方主题模块重建文本时剥掉颜色的问题。
- **「激活状态」卡**：通过心跳直接告诉你模块是否已在系统界面进程里跑起来。
- **App 内一键重启系统界面**：无需插线跑命令，重启后自动确认生效。
- **诊断与时钟探测**：把「为什么没生效」翻译成人话（仅 Probe / 调试版提供，正式版不含）。

### 设置页
- 标题「时间显秒」改为**粉尘点阵**：进入时由散点聚拢成字，点一下会炸开再聚回。

## 体验优化

- 预览卡展开/收起全程平滑过渡，尺寸锁定后不再跳动；数字下段不再被裁切。
- 「网络时间」行在高密度屏幕下不再溢出卡片，「同步」按钮不再被挤压。
- 关掉颜色总开关后，预览立即回到默认文字色。
- 单色模式下预览时间的冒号与数字**视觉居中对齐**。
- 深色 / 浅色主题分别适配，浅色主题下亮色自动按背景明暗校正，避免看不清。
- 卡片按压倾斜与音效、长弧刻度色板、无障碍朗读标签等细节保持完整。

## 问题修复

- **显秒后小时十位颜色被系统「洗」回去**（反馈最多）：在写入文本末尾补零宽空格，破坏系统的模式匹配，颜色得以保留。
- **「关了秒再打开，秒数不动」**：补上接管分支缺失的刷新计时器。
- **部分机型单击状态栏无反应（历史三星 One UI 反馈）**：修正触摸目标指向。
- **长按状态栏时钟无反应**：修正候选视图判定与刷新时机。
- **幂等判断误跳过重绘**：改为「文字 + 颜色标记」双重判断，掉色即补。
- **空闲时持续空转耗电**：改为自适应节流，判定真正掉色才加速，连续无异常自动停表。
- **预览渐变与状态栏渐变有色差**（仅个别亮色）：两边统一到同一套配色函数，并放宽对亮色的过度压暗。
- **个别分辨率下预览数字下半被裁**：按实测字形高度反推字号上限并加运行时兜底。
- **点击状态栏时间「没反应」**：实为任务窗口接管期间，现给出明确提示且不再改动总开关。
- **打开自定义任务界面时状态栏消失**：修正弹窗窗口标志。
- **设置页顶部多出一条空白带**：系统已为状态栏留白时不再重复留白。

## 行为变更与移除

- **移除「流动」功能**（含流动开关与速度滑杆）：只保留静态渐变，系统界面 CPU 占用回到基线水平（约 7%，远低于流动时的最高约 40%）。
- **移除「省电自适应」**：省电模式下不再暂停走秒，仅在熄屏 / 非交互时降低刷新频率。
- **移除「启用渐变」独立开关**：改由页签切换。
- **移除独立的「小时颜色」卡**：能力并入「逐位颜色」。
- 单色预设精简为 10 颗；「正在编辑：xx」提示行已移除。
- 四色渐变为阶段性尝试，本版仍为两色渐变。

## 安装与升级

1. 在 LSPosed 中启用本模块，作用域勾选 **com.android.systemui**。
2. 直接覆盖安装本版 APK（签名一致，无需卸载、不丢配置）。
3. **安装后需要重启系统界面**才会加载新代码：设置页内有「重启 SystemUI」按钮，或执行
   `adb shell su -c 'killall com.android.systemui'`。
4. 首次进入设置页即自动读取已有配置；颜色、渐变、任务均保存在系统设置数据库，重装不丢失。

## 已知限制

- **任务窗口建议 ≥ 5 分钟**：若设置「提前 2 分钟 + 持续 1 分钟」，窗口仅 1 分钟，极端情况下可能整段错过。
- **冒号颜色不可自定义**：ColorOS 以白色单独绘制冒号，不属于模块可着色的文本段。
- **不支持修改状态栏字体**：状态栏时钟为系统自有控件，模块只负责着色，不接管字体与排版。
- **渐变仅支持两色**。
