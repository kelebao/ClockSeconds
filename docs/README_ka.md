# დრო წამებით（Show Seconds in Time）

აჩვენეთ **წამები** სტატუსის ზოლის დროზე, გადართეთ ერთი შეხებით და დატოვეთ დროის **ათეულის ციფრი მუდმივად წითელი**.<br>ძირითადი გზა იყენებს მხოლოდ AOSP-ის საჯარო API-ებს (მწარმოებლის პრივატულ კლასებთან თავსებადობა არასავალდებულოა, მხოლოდ OPPO/OnePlus/realme-სთვის და გამოტოვდება თუ არ არსებობს). გადამოწმებული რეალურ მოწყობილობაზე ColorOS 15-ით; ასევე მოიცავს Xiaomi, OnePlus, Honor, vivo, Samsung-სა და სხვა დიდ მწარმოებლებს.

## ინსტალაცია

1. ჩამოტვირთეთ უახლესი APK გვერდიდან [**Releases**](https://github.com/kelebao/ClockSeconds/releases/latest)
2. ჩართეთ მოდული **LSPosed**-ში, ფარგლები: **სისტემის ინტერფეისი (`com.android.systemui`)**
3. გადატვირთეთ SystemUI-ის პროცესი ან გადატვირთეთ მოწყობილობა
4. პარამეტრების გვერდი გახსენით **LSPosed მმართველიდან** (ლაუნჩერში ხატულა არ ქმნება)

> საჭიროა root (LSPosed). `Settings.Secure`-ში ჩასაწერად მიანიჭეთ `WRITE_SECURE_SETTINGS`:
> ```bash
> adb shell pm grant io.github.kelebao.colorosclockseconds android.permission.WRITE_SECURE_SETTINGS
> ```
> მის გარეშეც შეგიძლიათ გადართოთ სტატუსის ზოლის დროის შეხებით (ეს მოქმედება SystemUI-ის პროცესში მიმდინარეობს, რომელსაც უფლება თავისდაპირველად აქვს).

## გამოყენება

- **შეეხეთ სტატუსის ზოლის დროს**: რთავს/თიშავს წამების ჩვენებას (ნაგულისხმევი ჟესტი).
- გადართვა გლობალური შეხების დამთხვევის შემოწმებით არის რეალიზებული, ამიტომ **არ ეწინააღმდეგება „შეტყობინების პანელის ჩამოწევას"**— სუფთა შეხება გადართავს, გასლისის დროს პანელი ჩამოდის როგორც ჩვეულებრივ. თუ ისეთი ჩვეულება გაქვთ, პარამეტრების გვერდზე ჟესტს **ხანგრძლივ დაჭერაზე** შეცვლით.
- პარამეტრების გვერდი აჩვენებს მიმდინარე მდგომარეობას, არჩეულ ჟესტს და განახლების ღილაკს.

## როგორ მუშაობს

მოდული მხოლოდ **SystemUI**-ს ჰუკავს, გამოყენებით გამოცდილი legacy Xposed მიდგომა,
და **ძირითადი გზა მხოლოდ AOSP-ის საჯარო API-ებს იყენებს, ხოლო მწარმოებლის პრივატულ კლასებთან თავსებადობა არასავალდებულოა და გამოტოვდება თუ არ არსებობს**, ამიტომ არ არღვევს სისტემის შიდა მდგომარეობას და არ აუქმებს LSPosed-ის უსაფრთხო რეჟიმს:

- **წამები**: ჰუკავს სტაბილურ `TextView.setText` (after)-ს, რათა დაკეშოს სისტემის მიერ სტატუსის ზოლის დროზე დაწერილი ნედლი ტექსტი, შემდეგ ჰუკავს `TextView.onDraw` (before)-ს, რათა სისტემის ტექსტის დაყენების შემდეგ ჩვენება თავზე გადააწეროს `ნედლი ტექსტი:ss`-ით, 1 წამიანი `Handler`-ის სარქველით. დამატებული წამები იღებენ დროის საკუთარი ტექსტის ფერს (გაზომილი `#ccffffff`). ასევე დროის ათეულის ციფრს ემატება წითელი `ForegroundColorSpan`, მიუხედავად იმისა ჩანს წამები თუ არა; წუთები და წამები არასდროს ჩადიან; ერთნიშნა დროს ათეული არ აქვს.
- **გადართვა**: ColorOS-ის შეტყობინების პანელი ხვევს სტატუსის ზოლის ზონაში შეხებებს, ამიტომ დროის საკუთარ `OnTouchListener` მოვლენებს არასდროს იღებს. მოდული ამიტომ ჰუკავს გლობალურ `View.dispatchTouchEvent`-ს და `Settings.Secure` გადამრთველს მხოლოდ მაშინ აბრუნებს, როცა დაჭერის წერტილი ამოცნობილი დროის ეკრანის საზღვრებში ვარდება და თითქმის არ მოძრაობს (შეხება) ან 350 მწ-ში მეორე შეხება (ორმაგი შეხება). მოდული **არ იხარჯავს** არც ერთ შეხების მოვლენას, ამიტომ შეტყობინების პანელის ჩამოწევა ჩვეულებრივ მუშაობს.

## ენერგიის დაზოგვის შენიშვნა

- **წამები ჩართული**: მოდულს სჭირდება 1 წამიანი ტაიმერი განახლების სტიმულირებისთვის (წამების ჩვენების თანდაყოლილი ხარჯი, დაახლოებით 60 დროის გადახატვა წუთში).
- **წამები გამორთული**: მოდული **მაშინვე წყვეტს ამ ტაიმერს** (`stopTicker`)— წამში აღორძინება აღარ არის და პროცესებს შორის კითხვა აღარ არის. ის ბრუნდება სისტემის საწყის რიტმზე „წუთში ერთხელ განახლება", ამიტომ წამების გამორთვა მართლაც დაზოგავს ენერგიას.
- მდგომარეობა ინახება **პროცესშიდა კეშში** (`sSecondsEnabled`), ამიტომ ტაიმერი წამში `Settings.Secure`-ს არ კითხულობს (წამში ერთხელ IPC-ს თავიდან აცილებს).
- დროის ფორმატირება არ ქმნება: მოდული ხელახლა იყენებს სისტემის ნედლ ტექსტს და მხოლოდ `:ss`-ს ამატებს, ამიტომ ფორმატირების ხარჯი ნულია.
- ტაიმერი მხოლოდ **სუსტ მინიშნებას** ინახავს ხედზე და მხოლოდ მაშინ გრძელდება, როცა ხედი `isAttachedToWindow()`-ია; ხედის განადგურების შემდეგ ავტომატურად გამოდის.

## აწყობა

საჭიროა **JDK 17+** (რეკომენდებულია 17 ან 21) და **Android SDK Platform 35** (Build-Tools 35-ს AGP ავტომატურად აყენებს).

```bash
export JAVA_HOME=/path/to/jdk-17-or-21
./gradlew assembleDebug
```

`ClockSeconds/` საქაღალდეში **ყველა ფაილი უნდა შენარჩუნდეს `build/`-ისა და `.gradle/`-ის გარდა** (კოდის ნაწილი მხოლოდ დაახლოებით 140 KB-ია):

| კატეგორია | ფაილი | შენიშვნა |
|------|------|------|
| აწყობის სკრიპტები | `settings.gradle.kts`, `build.gradle.kts`, `app/build.gradle.kts`, `gradle.properties` | ვერსია, დამოკიდებულებები, კომპილატორის პარამეტრები |

## პრობლემების მოგვარება

<details>
<summary>გახსენით პრობლემების მოგვარების ნაბიჯები</summary>

იხილეთ logcat:

- **Release აწყობები** აცილებს დიაგნოსტიკის ყველა ჟურნალს `BuildConfig.DEBUG`-ის კარლით (უფრო მცირე, უფრო სუფთა); logcat-ში ამ მოდულისგან არაფერი გამოდის.
- შესამოწმებლად დროებით დააყენეთ **debug აწყობი** (`assembleDebug`, ხელმოწერილი იმავე საწარმოო გასაღებით, ამიტომ პირდაპირ Release-ზე თავზე აყენებს) და გაფილტრეთ TAG-ით:

  ```bash
  adb logcat -s ColorOSClockSeconds
  ```

- თუ წამები სულაც არ ჩანს: ჯერ დარწმუნდით, რომ LSPosed-ში SystemUI ფარგლები მონიშნულია და გადატვირთულია; შემდეგ შეამოწმეთ, გადამრთველი გამორთულად არ შენახულა——
  adb-ით იკითხება / იძულებით ჩაწერება:

  ```bash
  adb shell settings get secure coloros_clock_seconds_enabled   # 1=ჩართ 0=გამორთ
  adb shell settings put  secure coloros_clock_seconds_enabled 1
  ```

- თუ ColorOS-ის გარეშე მოწყობილობაზე არ მოქმედებს: დააყენეთ debug აწყობი და ჟურნალში იხილეთ `candidate:` / `CONFIG CLOCK:` სტრიქონები,
  რომ ნახოთ, თქვენი მოწყობილობის სტატუსის ზოლის დროის რესურსის სახელი / კლასის სახელი ამოცნობის წესებში მოქცეულია; თუ არა, წესების კიდევ ერთი სტრიქონი საკმარისია.
