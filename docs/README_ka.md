# წამები სტატუსის ზოლში (Show Seconds in Time)

აჩვენებს **წამებს** სტატუსის ზოლის საათში, გადართვა შეხებით. შეგიძლიათ **თითოეულ ციფრს თავისი ფერი** მისცეთ ან მთელ ტექსტზე **გრადიენტი** დაადოთ.<br>**გრძელი დაჭერა** ხსნის ნახევრად გამჭვირვალე ფანჯარას **ქსელის დროით** (გადატანა, ზომა, გრადიენტი); **საკუთარი ამოცანები** წამებს სასურველ საათზე რთავს.<br>ძირითადი გზა მხოლოდ AOSP-ის საჯარო API-ებს იყენებს (OPPO / OnePlus / realme-ის დახურული კლასები არასავალდებულოა და არქონისას გამოტოვდება). შემოწმებულია ColorOS 15 / 16-ზე.

## დაყენება

1. ჩამოტვირთეთ APK გვერდიდან [**Releases**](https://github.com/kelebao/ClockSeconds/releases/latest)
2. ჩართეთ მოდული **LSPosed**-ში და მონიშნეთ არე **სისტემის ინტერფეისი** (`com.android.systemui`)
3. გადატვირთეთ SystemUI პროცესი ან მოწყობილობა
4. პარამეტრების ეკრანი იხსნება **LSPosed-ის მენეჯერიდან** (ლანჩერში ხატულა არ იქმნება)

> საჭიროა root (LSPosed). **ჩვეულებრივ adb-ის უფლებები არ სჭირდება**: ჩაწერა ხდება `Settings.Secure`-ით, ხოლო `WRITE_SECURE_SETTINGS`-ის არარსებობისას broadcast-ით, რომელსაც SystemUI ასრულებს. თუ გსურთ პარამეტრების ეკრანმა **პირდაპირ** ჩაწეროს:
> ```bash
> adb shell pm grant io.github.kelebao.colorosclockseconds android.permission.WRITE_SECURE_SETTINGS
> ```
> უფლების მიცემის გარეშეც ყველაფერი მუშაობს: შეხება, ამოცანები და ფანჯარა SystemUI-ში მუშაობს.

## როგორ მუშაობს

მოდული მხოლოდ **SystemUI**-ს აკავებს და იყენებს სტაბილურ legacy Xposed API-ს.
**ბირთვი მხოლოდ AOSP-ის საჯარო API-ებს ეყრდნობა, მწარმოებლის კლასები არასავალდებულოა და არქონისას გამოტოვდება**, ამიტომ სისტემას არ ამტვრევს და LSPosed-ის უსაფრთხო რეჟიმს არ იწვევს:

- **წამები**: `TextView.setText` (after) ინახავს სისტემის ტექსტს, შემდეგ `TextView.onDraw` (before) წერს `ორიგინალი:ss`-ს, განახლება ყოველ წამს `Handler`-ით.
- **ფერი თითო ციფრზე**: `ForegroundColorSpan` თითო სიმბოლოზე (უცხო span-ები მოიხსნება); წერტილები 0.11em-ით მაღლდება, რადგან მრავალსეგმენტიანი განლაგება გლიფს უფრო დაბლა აყენებს.
- **გრადიენტი**: `CharacterStyle` იძახებს `setShader`-ს `updateDrawState`-ში; გადახედვა **თავად იხატება** (`GradientTimeView`), რადგან ColorOS 15 შეიდერს ტექსტის სეგმენტებზე ატოლებს.
- **გადართვა**: პანელი სტატუსის ზოლის შეხებებს იჭერს, ამიტომ მოდული გლობალურად აკავებს `View.dispatchTouchEvent`-ს და მხოლოდ მაშინ ცვლის, როცა შეხება საათის შიგნითაა გადათრევის გარეშე; მოვლენა **არ მოიხმარება**.
- **ამოცანები**: შემოწმება „არის თუ არა ლოკალური დრო ინტერვალში", ზუსტი ტაიმერები საზღვრებზე და გადამოწმება ყოველ 60 წამს.

## ენერგიის ხარჯი

- **წამები ჩართულია**: ტაიმერი ყოველ წამს (გარდაუვალი ხარჯი). SystemUI ერთ ბირთვზე: 7.0% გამორთული, 7.25% ჩართული (60 წმ).
- **წამები გამორთულია**: ტაიმერი **მაშინვე ჩერდება** (`stopTicker`), ყოველწამიერი გაღვიძება არ არის.
- **ფერის დაცვა** ინელება 2s → 4s → … → 30s-მდე და წყდება 5 წუთში დანაკარგის გარეშე.
- მდგომარეობა **პროცესში ქეშირდება**; ამოცანები იყენებს `Handler.postDelayed`-ს: **WakeLock-ისა და AlarmManager-ის გარეშე**, ღრმა ძილს არ აღვიძებს.

```bash
export JAVA_HOME=/path/to/jdk-17-or-21

```

## პრობლემების მოგვარება

<details>
<summary>ნაბიჯების ჩვენება</summary>

ნახეთ logcat:

- **Release აწყობები** ყველა დიაგნოსტიკურ ჟურნალს მალავს `BuildConfig.DEBUG`-ის უკან.
- გამართვისთვის დააყენეთ **debug აწყობა** (`assembleDebug`, იგივე გასაღები) და გაფილტრეთ:

  ```bash
  adb logcat -s ColorOSClockSeconds
  ```

- წამები არ ჩანს: შეამოწმეთ „სისტემის ინტერფეისის" არე LSPosed-ში და გადატვირთეთ; შემდეგ წაიკითხეთ ან ჩაწერეთ გადამრთველი:

  ```bash
  adb shell settings get secure coloros_clock_seconds_enabled   # 1=on 0=off
  adb shell settings put  secure coloros_clock_seconds_enabled 1
  ```

- ფერები ან წამები თავისით ბრუნდება: სისტემა ან თემა ტექსტს ხელახლა აგებს და მოდული ხელახლა ხატავს; თუ არ აღდგა, debug ჟურნალში მოძებნეთ `color-guard stopped` / `span-theft`.

</details>
