# เวลาแสดงวินาที（Show Seconds in Time）

แสดง**วินาที**บนเวลาแถบสถานะ เปิด/ปิดด้วยการแตะครั้งเดียว และทำให้**หลักสิบของชั่วโมงเป็นสีแดง**เสมอ<br>เส้นทางหลักใช้เฉพาะ API สาธารณะของ AOSP (ความเข้ากันได้กับคลาสส่วนตัวของผู้ผลิตเป็นตัวเลือกเสริม เฉพาะ OPPO/OnePlus/realme และข้ามไปหากไม่มี) ยืนยันแล้วบนเครื่องจริง ColorOS 15 พร้อมรองรับ Xiaomi, OnePlus, Honor, vivo, Samsung และผู้ผลิตรายใหญ่อื่น ๆ

## ความสามารถ

| ความสามารถ | คำอธิบาย |
|------|------|
| แสดงวินาที | เวลาแถบสถานะแสดงถึงวินาที (`HH:mm:ss` / `h:mm:ss a` ตามการตั้งค่า 12/24 ชั่วโมงของระบบ) |
| แตะเพื่อเปิด/ปิด | **แตะ**เวลาแถบสถานะเพื่อเปิด/ปิดการแสดงวินาที สามารถเปลี่ยนเป็น**แตะสองครั้ง**ได้ในหน้าตั้งค่า |
| สีตัวเลขชั่วโมง | สี**หลักสิบของชั่วโมง**สามารถ**ปรับแต่ง**（ชุดสี 8 สี）หรือ**ปิด**เพื่อกลับสู่สีระบบ；ชั่วโมงที่เหลือหลักเดียว (เช่น `9:45`) ไม่มีหลักสิบจึงไม่ถูกแตะ ใช้ได้กับทุกผู้ผลิต |
| พรีวิวกดค้าง | **กดค้าง**เวลาแถบสถานะเพื่อเปิด**หน้าต่างลอยแบบฝ้า**แสดง**เวลาเครือข่าย**แบบเรียลไทม์ ลากเพื่อย้าย ดึง ◣ มุมซ้ายล่างเพื่อปรับขนาด แตะเวลาเพื่อแสดงปุ่ม**ปิด** (✕ ขวาบน) / **ปรับขนาด** ขนาดตัวอักษรปรับตามหน้าต่าง |
| เวลาเครือข่าย | หน้าตั้งค่าเปรียบเทียบ**เวลา标准เครือข่าย**แบบเรียลไทม์ ถ้าคลาดเคลื่อนมากให้แตะ**ซิงก์**เพื่อเปิดการตั้งเวลาอัตโนมัติของระบบ |
| ไม่ต้องใช้ adb | การตั้งค่าบันทึกลง `Settings.Secure` หากไม่มีสิทธิ์ `WRITE_SECURE_SETTINGS` จะสลับไปใช้บรอดคาสท์ที่ SystemUI ช่วยประมวลผล — **ไม่ต้องให้สิทธิ์ adb** |
| ภาษาของอินเทอร์เฟซ | อินเทอร์เฟซแอปรองรับ **21 ภาษา** (สลับตามภาษาของระบบอัตโนมัติ): 简体中文, English, 繁體中文, 日本語, 한국어, Türkçe, Русский, Tiếng Việt, ไทย, Deutsch, Español, Français, Українська, Polski, Português (Brasil), فارسی, العربية, Bahasa Indonesia, Italiano, Ελληνικά, ქართული |
| การเก็บสถานะถาวร | สถานะเก็บไว้ใน `Settings.Secure` ใช้ร่วมระหว่างโปรเซส และคงอยู่หลังจากรีสตาร์ท SystemUI |
| ขอบเขตการรองรับ | ยืนยันแล้วบน ColorOS 15 / 16 / 17 (OPPO / OnePlus / realme) และทำงานได้ทันทีบนผู้ผลิตอื่น ๆ ที่รูทแล้ว เช่น Xiaomi / Honor / Redmi / Samsung เส้นทางหลักใช้เฉพาะ API สาธารณะของ AOSP จึงไม่ทำให้ LSPosed เข้าสู่โหมดปลอดภัย รองรับต่ำถึง Android 10 |
| เทมเพลตด่วน | เพิ่มไทล์ "แสดงวินาที" ในบานหน้าต่างการแจ้งเตือน เปิด/ปิดด้วยแตะเดียว |
| พื้นที่ลอย | ตำแหน่งและขนาดหน้าต่างลอย**ถูกจดจำ**; **แตะสองครั้ง**ที่เวลาก็สลับวินาที |
| ประหยัดพลังงาน | เปิดโหมดประหยัดแบตเตอรี่จะหยุดรีเฟรชวินาที (วินาทีค้าง) ปิดแล้วกลับมาทันที |
| ปรับแต่งการจับคู่ได้ | หากนาฬิกาไม่ถูกจับคู่อัตโนมัติ ให้แตะ **ตรวจจับอัตโนมัติ** ในการตั้งค่า หรือป้อนชื่อทรัพยากร (เช่น clock) ด้วยตนเอง |

## การติดตั้ง

1. ดาวน์โหลด APK รุ่นล่าสุดจากหน้า [**Releases**](https://github.com/kelebao/ClockSeconds/releases/latest)
2. เปิดใช้โมดูลใน **LSPosed** ขอบเขต: **อินเทอร์เฟซระบบ (`com.android.systemui`)**
3. รีสตาร์ทโปรเซส SystemUI หรือรีบูตเครื่อง
4. เปิดหน้าตั้งค่าจาก **ตัวจัดการ LSPosed** (ไม่สร้างไอคอนบนหน้าจอหลัก)

> ต้องมีรูท (LSPosed) การเขียน `Settings.Secure` ต้องให้สิทธิ์ `WRITE_SECURE_SETTINGS`:
> ```bash
> adb shell pm grant io.github.kelebao.colorosclockseconds android.permission.WRITE_SECURE_SETTINGS
> ```
> หากยังไม่ให้สิทธิ์ ก็ยังแตะเวลาแถบสถานะเพื่อเปิด/ปิดได้ (การกระทำนี้ทำงานอยู่ในโปรเซส SystemUI ซึ่งมีสิทธิ์อยู่แล้ว)

## วิธีใช้

- **แตะเวลาแถบสถานะ**: เปิด/ปิดการแสดงวินาที (ท่ามือเริ่มต้น)
- การเปิด/ปิดทำผ่านการตรวจจับการแตะแบบทั่วระบบ จึง**ไม่ขัดแย้งกับการ"ดึงแผงแจ้งเตือนลง"**——แตะล้วนเพื่อเปิด/ปิด ส่วนการปัดยังดึงแผงแจ้งเตือนลงตามปกติ ถ้าถนัดกว่านั้นสามารถเปลี่ยนท่ามือเป็น**แตะสองครั้ง**ได้ในหน้าตั้งค่า
- หน้าตั้งค่าสามารถดูสถานะปัจจุบัน ท่ามือที่เลือก และรีเฟรชสถานะได้

## หลักการทำงาน

โมดูลฮุคเพียง**โปรเซส SystemUI** เท่านั้น ใช้แนวทาง legacy Xposed ที่ผ่านการยืนยันแล้ว
**เส้นทางหลักใช้เฉพาะ API สาธารณะของ AOSP ส่วนความเข้ากันได้กับคลาสส่วนตัวของผู้ผลิตเป็นตัวเลือกเสริมและข้ามไปหากไม่มี** เพราะฉะนั้นไม่ทำให้สถานะภายในของระบบเสียหาย และไม่ทำให้ LSPosed เข้าสู่โหมดปลอดภัย:

- **แสดงวินาที**: ฮุค `TextView.setText` (after) ที่เสถียร เพื่อแคชข้อความดั้งเดิมที่ระบบใส่ไว้บนเวลาแถบสถานะ
  จากนั้นฮุค `TextView.onDraw` (before) เพื่อเขียนทับการแสดงผลเป็น `ข้อความดั้งเดิม:ss` หลังจากระบบตั้งข้อความเรียบร้อยแล้ว
  ขับเคลื่อนด้วย `Handler` ระยะ 1 วินาที วินาทีที่ถูกเพิ่มเข้ามาจะคงสีข้อความเดิมของเวลาของระบบ (วัดได้เป็น `#ccffffff`)
  พร้อมกับระบายสีแดงให้"หลักสิบของชั่วโมง" (เติมชุดสีแดง `ForegroundColorSpan`ให้ตัวอักษรนั้น) ไม่ว่าการแสดงวินาทีจะเปิดหรือปิด ก็ยังคงสีแดงไว้
  ไม่ระบายสีแดงนาทีและวินาที ชั่วโมงที่เหลือหลักเดียวไม่มีหลักสิบจึงไม่ถูกแตะ
- **เปิด/ปิด**: แผงแจ้งเตือนของ ColorOS ขัดขวางการแตะในบริเวณแถบสถานะ ดังนั้น `OnTouchListener` ของเวลาเองจึงไม่ได้รับเหตุการณ์เลย
  โมดูลจึงเปลี่ยนไปฮุค `View.dispatchTouchEvent` ของระบบทั่วทั้งหมด และพลิกสวิตช์ `Settings.Secure` เมื่อจุดกดตกอยู่ในกรอบหน้าจอ
  ของเวลาที่จำได้ และเคลื่อนที่เกือบไม่มี (การแตะ) หรือเป็นการแตะครั้งที่สองภายใน 350 มิลลิวินาที (แตะสองครั้ง) โมดูล**ไม่กลืนเหตุการณ์การแตะใด ๆ ทั้งสิ้น**
  เพราะฉะนั้นการดึงแผงแจ้งเตือนลงยังทำงานตามปกติ

## หมายเหตุเรื่องการประหยัดไฟ

- **เมื่อเปิดการแสดงวินาที**: โมดูลต้องใช้ตัวจับเวลาระยะ 1 วินาทีขับการรีเฟรช (นี่คือต้นทุนอยู่ในตัวของ"การแสดงวินาที" ประมาณ 60 ครั้งต่อนาทีของการวาดเวลาใหม่)
- **เมื่อปิดการแสดงวินาที**: โมดูลจะ**หยุดตัวจับเวลาเหล่านั้นทันที** (`stopTicker`) ไม่มีการตื่นทุกวินาทีอีกต่อไป และไม่มีการอ่านข้ามโปรเซส
  กลับไปอยู่ในจังหวะ"รีเฟรชครั้งเดียวต่อนาที"แบบเดิมของระบบ เพราะฉะนั้นการปิดการแสดงวินาที จึงประหยัดพลังงานได้จริง
- สถานะถูกเก็บใน**แคชภายในโปรเซส** (`sSecondsEnabled`) ตัวจับเวลาไม่ไปอ่าน `Settings.Secure` ทุกวินาที (หลีกเลี่ยง IPC ทุกวินาที)
- โมดูลไม่สร้างตัวจัดรูปแบบเวลาใด ๆ ใช้ข้อความดั้งเดิมของระบบซ้ำแล้วเพียงต่ออกดู `:ss` เพราะฉะนั้นไม่มีโหลดจากตัวจัดรูปแบบ
- ตัวจับเวลาระยะถือ**การอ้างอิงแบบอ่อน**ต่อวิวเท่านั้น และทำงานต่อก็ต่อเมื่อวิวยัง `isAttachedToWindow()` เมื่อวิวถูกทำลายจะออกจากวงเองโดยอัตโนมัติ

## การ Build

ต้องมี **JDK 17+** (แนะนำ 17 หรือ 21) และ **Android SDK Platform 35** (Build-Tools 35 ติดตั้งเองโดย AGP)

```bash
export JAVA_HOME=/path/to/jdk-17-or-21
./gradlew assembleDebug
```

## การแก้ไขปัญหา

<details>
<summary>ขยายขั้นตอนการแก้ไขปัญหา</summary>

ดู logcat:

- **บิลด์ Release** ใช้เงื่อนไข `BuildConfig.DEBUG` กรองล็อกวินิจฉัยออกหมดแล้ว (เล็กลง สะอาดขึ้น) logcat จะไม่แสดงล็อกของโมดูลนี้
- หากต้องตรวจสอบ ให้ติดตั้ง**บิลด์ debug**ชั่วคราว (`assembleDebug` เซ็นด้วยproduction key ตัวเดียวกับของรุ่นปล่อย จึงติดตั้งทับของ release ได้ตรง ๆ) จากนั้นกรองด้วย TAG:

  ```bash
  adb logcat -s ColorOSClockSeconds
  ```

- ถ้าไม่แสดงวินาทีเลย: ขอเช็กก่อนว่า LSPosed ติ๊กระยะ SystemUI และรีสตาร์ทแล้ว จากนั้นเช็กว่าสวิตช์ถูกบันทึกไว้ว่าปิดอยู่——
  อ่าน / บังคับเขียนผ่าน adb ได้:

  ```bash
  adb shell settings get secure coloros_clock_seconds_enabled   # 1=เปิด 0=ปิด
  adb shell settings put  secure coloros_clock_seconds_enabled 1
  ```

- ถ้าไม่มีผลบนเครื่องที่ไม่ใช่ ColorOS: ติดตั้งบิลด์ debug ดูล็อกที่บรรทัด `candidate:` / `CONFIG CLOCK:`
  เพื่อยืนยันว่าชื่อรีซอร์ส / ชื่อคลาสของเวลาแถบสถานะบนเครื่องนั้น อยู่นอกกฎการจำหรือเปล่า ถ้าอยู่นอก เพียงเติมกฎหนึ่งบรรทัดก็เพียงพอ

</details>
