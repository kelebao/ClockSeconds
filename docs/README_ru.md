# Секунды в строке состояния (Show Seconds in Time)

Показывает **секунды** во времени строки состояния, переключение касанием. Можно задать **цвет каждой цифры** или растянуть **градиент** по всей строке.<br>**Долгое нажатие** открывает полупрозрачное окно с **сетевым временем** (перетаскивание, размер, градиент); **свои задачи** включают секунды в нужный час.<br>Основной путь использует только открытые API AOSP (закрытые классы OPPO / OnePlus / realme — необязательно, при отсутствии пропускаются). Проверено на ColorOS 15 / 16.

## Возможности

| Возможность | Описание |
|------|------|
| Секунды в строке состояния | `HH:mm:ss` / `h:mm:ss a`, учитывает 12/24-часовой формат и часовой пояс. В конец добавляется **пробел нулевой ширины**, чтобы темы не сбрасывали цвета, при потере цвета текст перерисовывается автоматически (пауза 5 минут). |
| Переключение касанием | **Касание** включает и выключает секунды (можно выбрать **двойное касание**); **долгое нажатие** зарезервировано для окна просмотра. Внутри задачи показывается «управляется задачей». |
| Цвет по цифрам / градиент | Шесть цифр **каждая своим цветом** (10 предустановок + ползунки HSV + как в системе); двоеточия центрируются оптически. Либо **градиент** от начального к конечному (6 наборов, оба конца настраиваются, на светлом фоне затемняется). Карточка просмотра **рисуется сама** и совпадает со строкой состояния. |
| Окно по долгому нажатию | Полупрозрачное окно с **сетевым временем**; перетаскивание, размер за угол ◣, положение и размер **запоминаются**; градиент и моноширинные цифры. |
| Свои задачи | Окна **каждый час** или **каждый день**: включить секунды за N минут на M минут, затем вернуть. Изменение времени или пояса пересчитывается сразу, плюс резерв каждые 60 секунд. |
| Сравнение с сетевым временем | Показывает расхождение с **сетевым временем**; кнопка **Синхронизировать** включает системную автонастройку. |
| Права adb не нужны | Запись идёт через `Settings.Secure`; без `WRITE_SECURE_SETTINGS` используется broadcast и пишет SystemUI — **adb не требуется** ни для одной функции. |
| Плитка в шторке | Добавьте плитку «Секунды», чтобы переключать, не открывая приложение. |
| Имя ресурса часов | Если часы не распознаны, нажмите **Автоопределение** или введите имя ресурса (например `clock`). |
| 21 язык интерфейса | Интерфейс следует языку системы: 简体中文, English, 繁體中文, 日本語, 한국어, Türkçe, Русский, Tiếng Việt, ไทย, Deutsch, Español, Français, Українська, Polski, Português (Brasil), فارسی, العربية, Bahasa Indonesia, Italiano, Ελληνικά, ქართული; остальные — английский. |
| Сохранение / охват | Состояние хранится в `Settings.Secure`, общее для процессов, сохраняется после перезапуска. **Проверено на ColorOS 15 / 16 (Android 15 / 16)**; ядро использует только открытые API, поэтому другие производители должны работать, но тестировались только OPPO / OnePlus. Минимум Android 10. |

## Установка

1. Скачайте APK со страницы [**Releases**](https://github.com/kelebao/ClockSeconds/releases/latest)
2. Включите модуль в **LSPosed** и задайте область **Системный интерфейс** (`com.android.systemui`)
3. Перезапустите процесс SystemUI или устройство
4. Экран настроек открывается из **менеджера LSPosed** (значок в лончере не создаётся)

> Нужен root (LSPosed). **Права adb обычно не нужны**: запись идёт через `Settings.Secure`, а без `WRITE_SECURE_SETTINGS` — через broadcast, пишет SystemUI. Чтобы экран настроек писал **напрямую**, выдайте:
> ```bash
> adb shell pm grant io.github.kelebao.colorosclockseconds android.permission.WRITE_SECURE_SETTINGS
> ```
> Без выдачи ничего не меняется: касания, задачи и окно работают внутри SystemUI, где права уже есть.

## Использование

- **Коснитесь времени**: секунды вкл/выкл (по умолчанию); в настройках можно выбрать **двойное касание**.
- **Долгое нажатие**: окно с **сетевым временем**, перетаскивание, по касанию появляются кнопки **закрыть** (справа сверху) и **размер** (слева снизу).
- Карточка **Цвета цифр** имеет две страницы, вкладка сама является переключателем.
- Карточка **Свои задачи** планирует «включить секунды за 2 минуты до каждого часа» и наоборот.
- Переключение использует глобальную проверку касания и **не конфликтует со шторкой**.
- Экран настроек показывает состояние, жест, цвета, разницу с сетью и **синхронизацию** в один тап.

## Как это работает

Модуль хукает только **SystemUI** и использует консервативный legacy Xposed API.
**Ядро опирается только на открытые API AOSP, закрытые классы вендоров необязательны и при отсутствии пропускаются**, поэтому не ломает систему и не вызывает безопасный режим LSPosed:

- **Секунды**: `TextView.setText` (after) кеширует системный текст, `TextView.onDraw` (before) пишет `исходный:ss`, обновление раз в секунду через `Handler`.
- **Цвет по цифрам**: `ForegroundColorSpan` на цифру (внешние span снимаются); двоеточие поднимается на 0.11em через `CharacterStyle`.
- **Градиент**: `CharacterStyle` с `setShader` в `updateDrawState`; предпросмотр в настройках **рисуется сам** (`GradientTimeView`), потому что ColorOS 15 квантует shader по run.
- **Переключение**: панель уведомлений перехватывает касания, поэтому хукается глобальный `View.dispatchTouchEvent`; переключение только при нажатии внутри границ часов. Событие **не потребляется**.
- **Задачи**: «попадает ли локальное время в окно», точные таймеры границ плюс резерв 60 секунд.

## Энергопотребление

- **Секунды вкл**: таймер раз в секунду. Замер SystemUI на ядро: 7.0% без секунд, 7.25% с ними (60 с).
- **Секунды выкл**: таймер **сразу останавливается** (`stopTicker`), пробуждений нет.
- **Защита цвета** отступает 2s → 4s → … → 30s и прекращается через 5 минут без потерь.
- Состояние **кешируется в процессе**, таймер не читает `Settings.Secure` каждую секунду.
- Резерв задач на `Handler.postDelayed`: **без WakeLock и AlarmManager**, глубокий сон не будится.

## Сборка

Нужны **JDK 17+** (17 или 21) и **Android SDK Platform 35** (Build-Tools 35 скачает AGP).

```bash
export JAVA_HOME=/path/to/jdk-17-or-21
./gradlew assembleDebug
```

## Диагностика

<details>
<summary>Показать шаги</summary>

Смотрите logcat:

- **Release-сборки** скрывают все диагностические логи за `BuildConfig.DEBUG`.
- Для отладки поставьте **debug-сборку** (`assembleDebug`, подписана тем же ключом) и фильтруйте:

  ```bash
  adb logcat -s ColorOSClockSeconds
  ```

- Секунд нет совсем: проверьте область System UI в LSPosed и перезапустите; затем прочитайте или задайте ключ:

  ```bash
  adb shell settings get secure coloros_clock_seconds_enabled   # 1=вкл 0=выкл
  adb shell settings put  secure coloros_clock_seconds_enabled 1
  ```

- Цвета или секунды возвращаются сами: система или тема перестраивает текст, модуль перерисовывает; если не восстанавливается, ищите в debug-логе `color-guard stopped` / `span-theft`.
- Не работает вне ColorOS: в debug-сборке смотрите `candidate:` / `CONFIG CLOCK:` — совпадает ли класс или имя ресурса с правилами определения.

</details>
