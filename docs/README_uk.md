# Секунди в часі（Show Seconds in Time）

Показуйте **секунды** в часі в рядку стану, перемикайте одним дотиком і тримайте **десяток часу червоним**.<br>Жодних приватних класів виробника. Перевірено на реальному пристрої з ColorOS 15; також розраховано на Xiaomi, OnePlus, Honor, vivo, Samsung та інших великих виробників.

## Можливості

| Можливість | Опис |
|------|------|
| Секунди | Годинник у рядку стану показує секунди (`HH:mm:ss` / `h:mm:ss a`, відповідає системному формату 12/24 години) |
| Дотик для перемикання | **Дотик** до часу в рядку стану перемикає показ секунд; на сторінці налаштувань можна вибрати **подвійне натискання** |
| Колір десятка часу | Колір **десятка часу** можна **налаштувати** (палітра з 8 кольорів) або **вимкнути**, повернувши системний колір; при однозначному часу (напр. `9:45`) десятка немає, вона не торкається. Діє на всіх виробників |
| Попередній перегляд довгим натисканням | **Довге натискання** на час у рядку стану відкриває **напівпрозоре матове вікно** з **мережевим часом** у реальному часі; перетягування, зміна розміру за ◣ (зліва внизу), натискання на час показує кнопки **закрити** (✕ зверху справа) / **розтягнути**; розмір шрифту адаптується до вікна |
| Мережевий час | Сторінка налаштувань порівнює годинник з **мережевим стандартним часом**; за великого розбіжності натисніть **Синхронізувати**, щоб увімкнути автоматичне встановлення часу |
| Без adb | Налаштування пишуться в `Settings.Secure`; без дозволу `WRITE_SECURE_SETTINGS` модуль автоматично переходить на широкомовлення, яке обробляє SystemUI — **права adb не потрібні** |
| Мови інтерфейсу | Інтерфейс застосунку локалізовано на **21 мову** (автоматично йде за системною мовою): 简体中文, English, 繁體中文, 日本語, 한국어, Türkçe, Русский, Tiếng Việt, ไทย, Deutsch, Español, Français, Українська, Polski, Português (Brasil), فارسی, العربية, Bahasa Indonesia, Italiano, Ελληνικά, ქართული |
| Збереження стану | Стан зберігається в `Settings.Secure`, спільний між процесами й зберігається після перезапуску SystemUI |
| Сумісність | Перевірено на ColorOS 15 / 16 / 17 (OPPO / OnePlus / realme); також працює «з коробки» на інших виробниках із root, як-от Xiaomi / Honor / Redmi / Samsung. Без приватних класів виробника, тому безпечний режим LSPosed не спрацьовує. Мінімум Android 10 |
| Швидка плитка | Додайте плитку "Показувати секунди" у шторку, перемкніть одним дотиком |
| Покращення плаваючого | Позиція та розмір вікна **запам'ятовуються**; **подвійний тап** по часу теж перемикає |
| Енергозбереження | У режимі економії оновлення покроково призупиняється (секунди завмирають), після вимкнення — одразу поновлюється |
| Налаштовуване розпізнавання | Якщо годинник не визначається на іншому пристрої, натисніть «Автовизначення» у налаштуваннях або вкажіть ім'я ресурсу (напр. clock) вручну |

## Встановлення

1. Завантажте останній APK зі сторінки [**Releases**](https://github.com/kelebao/ClockSeconds/releases/latest)
2. Увімкніть модуль у **LSPosed**, область: **Системний інтерфейс (`com.android.systemui`)**
3. Перезапустіть процес SystemUI або перезавантажте пристрій
4. Сторінку налаштувань відкривайте з **менеджера LSPosed** (значок на робочому столі не створюється)

> Потрібен root (LSPosed). Щоб надати дозвіл `WRITE_SECURE_SETTINGS` для запису в `Settings.Secure`:
> ```bash
> adb shell pm grant io.github.kelebao.colorosclockseconds android.permission.WRITE_SECURE_SETTINGS
> ```
> Без дозволу перемикання все одно працює дотиком до часу в рядку стану (ця дія виконується всередині процесу SystemUI, який уже має право).

## Використання

- **Дотик до часу в рядку стану**: перемикає показ секунд (жест за умовчанням).
- Перемикання реалізовано через глобальне попадання по дотику, тому воно **ніколи не конфліктує зі «свайпом шторки повідомлень»**—— чистий дотик перемикає, свайп як і раніше опускає шторку. За бажанням жест можна змінити на **подвійне натискання** на сторінці налаштувань.
- Сторінка налаштувань показує поточний стан, вибраний жест і кнопку оновлення.

## Як це працює

Модуль перехоплює лише **SystemUI**, використовуючи перевірений підхід legacy Xposed,
і **жодного разу не торкається приватних класів виробника**, тому внутрішній стан системи не ламається й безпечний режим LSPosed не спрацьовує:

- **Секунди**: хук стабільного `TextView.setText` (after) кешує вихідний текст, який система виводить на час рядку стану,
  потім хук `TextView.onDraw` (before) після встановлення тексту системою перезаписує відображення на `вихіднийТекст:ss`,
  керований `Handler` із періодом 1 секунда. Додані секунди успадковують власний колір тексту часу (виміряно `#ccffffff`).
  Додатково десяток часу забарвлюється червоним (червоний `ForegroundColorSpan` на цьому одному символі)— червоний тримається і за увімкненого, і за вимкненого показу секунд;
  хвилини й секунди не забарвлюються; за однозначної часу десятка немає й вона не торкається.
- **Перемикання**: панель повідомлень ColorOS перехоплює дотики в області рядку стану, тому власний `OnTouchListener` часу подій не отримує.
  Модуль тому перехоплює глобальний `View.dispatchTouchEvent` і перемикає `Settings.Secure` лише коли натискання потрапляє
  в межі розпізнаного часу на екрані та майже не зміщується (дотик) або це другий дотик протягом 350 мс (подвійне натискання). Модуль **не споживає**
  жодної події дотику, тому свайп шторки повідомлень працює як завжди.

## Економія заряду

- **Секунди УВІМКНЕНІ**: модулю потрібен таймер з періодом 1 секунда для оновлень (непідмінна ціна показу секунд— близько 60 перемальовувань часу на хвилину).
- **Секунди ВИМКНЕНІ**: модуль **негайно зупиняє цей таймер** (`stopTicker`)— жодних посекундних пробуджень і міжпроцесних читань.
  Він повертається до вихідного ритму системи «оновлення раз на хвилину», тому вимкнення показу секунд справді економить заряд.
- Стан кешується **всередині процесу** (`sSecondsEnabled`), тому таймер не читає `Settings.Secure` щосекунди (що уникає посекундного IPC).
- Жодних форматувальників часу не створюється: модуль використовує повторно вихідний текст системи й лише додає `:ss`, тому накладних витрат на форматування немає.
- Таймер тримає лише **слабке посилання** на подання і продовжує роботу, поки подання `isAttachedToWindow()`; після знищення подання виходить автоматично.

## Збірка

Потрібні **JDK 17+** (рекомендовано 17 або 21) і **Android SDK Platform 35** (Build-Tools 35 встановлюється автоматично через AGP).

```bash
export JAVA_HOME=/path/to/jdk-17-or-21
./gradlew assembleDebug
```

## Резервна копія та продовження розробки (важливо)

У каталозі `ClockSeconds/` потрібно зберігати **всі файли, крім `build/` і `.gradle/`** (вихідний код важить лише близько 140 КБ):

| Категорія | Файл | Примітка |
|------|------|------|
| Скрипти збірки | `settings.gradle.kts`, `build.gradle.kts`, `app/build.gradle.kts`, `gradle.properties` | Версія, залежності, параметри компіляції |
| Gradle Wrapper | `gradlew`, `gradlew.bat`, `gradle/wrapper/*` | Фіксує Gradle 8.14.5 |
| Вихідний код | `app/src/main/java/**` (3 файли `.java`) | Основна логіка модуля |
| Ресурси | `app/src/main/res/**` | Рядки (китайська за умовчанням + 21 локаль values-xx), тема |
| Метадані Xposed | `app/src/main/resources/META-INF/xposed/*` | Клас входу, область, версія API |
| Маніфест | `app/src/main/AndroidManifest.xml` | Дозволи, Activity |
| Документація | `README*.md` | Документація 21 мовою |
| CI | `.github/workflows/release.yml` | Підписані збірки за тегом |

## Діагностика

<details>
<summary>Розгорнути кроки діагностики</summary>

Перевірте logcat:

- **Release-збірки** вирізають усю діагностичну логування через гейт `BuildConfig.DEBUG` (менше й чище); у logcat від цього модуля нічого немає.
- Для діагностики тимчасово встановіть **debug-збірку** (`assembleDebug`, підписану тим самим продуктовим ключем, тому її можна поставити поверх Release), потім фільтруйте за TAG:

  ```bash
  adb logcat -s ColorOSClockSeconds
  ```

- Якщо секунди не показуються взагалі: спочатку переконайтесь, що в LSPosed відмічена область SystemUI і виконано перезапуск; потім перевірте, чи не зберігся перемикач як вимкнений—
  прочитати / примусово записати через adb:

  ```bash
  adb shell settings get secure coloros_clock_seconds_enabled   # 1=увімк 0=вимкн
  adb shell settings put  secure coloros_clock_seconds_enabled 1
  ```

- Якщо не працює на пристрої без ColorOS: встановіть debug-збірку й подивіться рядки `candidate:` / `CONFIG CLOCK:` у логу,
  щоб зрозуміти, чи покриті ім'я ресурсу / ім'я класу часу рядку стану вашого пристрою правилами розпізнавання; якщо ні— досить додати один рядок правила.

</details>
